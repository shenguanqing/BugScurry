# 平台差异与注意事项

[English](platforms.md)

最近一次 macOS 实测：**2026-09-16**（含合盖睡眠唤醒 soak）· Apple M1 Pro · macOS 15.7.9 · 内置 Retina 3024×1964@2x + 外接 1920×1080。Spaces soak 另见 2026-09-11。

- 开发路径：`pnpm tauri dev`（debug + Vite）
- 生产路径：用户执行 `pnpm tauri build` 后的 `BugScurry.app` / `BugScurry_0.4.0_aarch64.dmg`（已补测）

Windows 列本机尚未实机验证。

## macOS

### 窗口

- 透明 + 无边框：`transparent: true`, `decorations: false`
- 始终置顶：`alwaysOnTop: true`，必要时 level 调整
- 不抢焦点：覆盖层 `focusable: false`（设置窗口除外）
- Menu Bar 使用托盘图标 + 菜单（不是 Dock 主入口）
- 全屏应用 / Stage Manager：置顶窗口可能被系统遮挡，属系统策略
- **Spaces：** 覆盖层 `visibleOnAllWorkspaces`，切换桌面时虫子跟随
- 托盘隐藏对所有覆盖窗口调用原生 `hide()`，使透明窗口退出 macOS 窗口截图选择；显示时恢复覆盖层且不抢焦点。
- 截图偏好：默认 `showInCaptures: false`，截图会话期间临时隐藏所有原生覆盖窗口（托盘隐藏优先），会话结束约 400 ms 后恢复。检测只匹配截图快捷键，事件原样通过、不存数据，需要「输入监控」或「辅助功能」权限，设置窗口会指引授权。不开内容保护，避免窗口截图在选中覆盖层时失败。实现细节见[架构 §9.3](../architecture.zh-CN.md#93-截图偏好)。
- 会话速览：`⌘⇧4` 式选择在松开鼠标 / Esc / Enter 后结束；`⌘⇧5` 在截图文件存好后结束（存剪贴板需按 Esc）；Esc 或 `⌘⌃Esc` 可结束一切（含录屏中）。不覆盖：按键即拍的 `⌘⇧3`、超长录屏、未配置的第三方工具。ScreenCaptureKit 场景没有公开防截图 API（Apple DTS，macOS 15.4+）。[Apple 答复](https://developer.apple.com/forums/thread/792152)。

### 鼠标穿透

- `setIgnoreCursorEvents(true)` ↔ AppKit `NSWindow.ignoresMouseEvents`
- 无官方 `forward` 模式，需自建坐标转发或动态开关
- 动态开关时注意点击丢失窗口约一帧

### Retina

- `window.devicePixelRatio` 为 2
- Canvas backing store 必须乘 dpr
- CGEvent 光标是全局**逻辑点**，需按窗口 origin/scale 换算

### 兼容

- Apple Silicon（arm64）与 Intel（x64）分别打包或 universal
- 最低系统版本建议在 `tauri.conf.json` 与 README 标明

### 运行时结论（已实测）

| 主题 | 发现 |
|------|------|
| 开发模式 vs 裸 `cargo build --release` | `pnpm tauri dev` 走 `http://localhost:1420`，**必须先有 Vite**。单独跑 `target/debug/bugscurry` 时 WebView 为空白。生产资源应用 `pnpm tauri build` 生成；仅 `cargo build --release` 可能未正确嵌入 `frontendDist`。 |
| 覆盖层绘制 | 生产包 `BugScurry.app`：主屏 overlay 截屏可见不透明虫体像素，其余区域透明。 |
| 多显示器 | `monitorMode: "all"` 在 dev 与生产包均会创建第二块屏覆盖层。 |
| 设置窗口 | 默认隐藏（`onscreen=false`）；覆盖层主循环不依赖设置窗口是否打开。 |
| 设置与覆盖层层级（0.3+） | 打开设置**不要**降低覆盖层 `always_on_top`。覆盖层保持置顶，虫子仍可见；设置负责 show / focus。除碰到虫子外点击穿透。 |
| 天气（0.3+） | 托盘：停止 + 五档雨 / 雪 / 雾 / 沙尘，并勾选当前档。环境声程序化（仅主覆盖层）；停止/隐藏/关音效时硬静音。雷为延迟低频滚雷；沙尘共用阵风包络偏风噪。 |
| 投喂特效（0.3+） | 性格 + 虫种吃相；蚂蚁搬运时口器前画碎屑；水果吃完留 `__juice` 淡印；餐后暖光。 |
| 产物 | `src-tauri/target/release/bundle/macos/BugScurry.app` · `dmg/BugScurry_0.4.0_aarch64.dmg`（arm64） |

## Windows

### 窗口

- 透明无边框置顶：对应 WS_EX_LAYERED / TOPMOST / TOOLWINDOW 等由 Tauri 封装
- `skipTaskbar: true` 避免任务栏按钮
- WebView2 运行时依赖：安装器需处理 bootstrapper
- 托盘隐藏/显示修改所有覆盖窗口的原生可见状态，与 macOS 共用同一状态。
- 截图偏好关闭 `showInCaptures` 时请求 `WDA_EXCLUDEFROMCAPTURE`，从 Windows 10 2004 起支持，更早版本按 `WDA_MONITOR` 处理。作用于支持的系统截图方式，依赖桌面合成；实际截图工具的覆盖情况仍未验证。[Microsoft API 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)。

### 鼠标穿透

- 对应 layered window 的 click-through 标志
- 同样建议只在命中变化时切换

### DPI

- 系统缩放 100% / 125% / 150% / 200%
- 混合 DPI 多显示器（笔记本 150% + 外接 100%）是重点测试项
- 行为模拟与命中一律逻辑像素

### 兼容

- x64 为主；ARM64 作为兼容目标验证 WebView2 与托盘

**状态：** CI 可产出 NSIS 安装包；本机尚未做 Windows 实机 soak，下表 Windows 列均为待测。

## 多显示器

| 问题 | 处理 |
|------|------|
| 分辨率不同 | 每显示器独立窗口与 viewport |
| 缩放不同 | 各窗口独立 dpr |
| 主屏切换 / 插拔 | 监听变化，重建窗口并保留共享的原生可见状态 |
| 「当前屏幕」 | 主屏（UI 文案需写清） |

## 性能检查清单

### 生产包（`pnpm tauri build` · BugScurry.app · M1 Pro）

- [x] 1 虫空闲 CPU — **2026-10-06 复测（release，macOS 15.8.1，arm64）：合计约 15.6%** — 主进程约 7.7% + 覆盖层 WebView 约 7.9%（10s `top` 采样，主屏 ProMotion，萤火虫，静默设置）。较历史 **4.8%** 上升：0.4.x 的虫种/天气打磨使每帧开销接近翻倍。本次修改已将污渍与光晕渐变烘焙为 sprite，帧循环不再新建渐变。
- [x] 10 虫 — 合计约 **10.4%**（主进程 ~4.4% + WebView ~6.0%），同条件
- [x] 50 虫 — 合计约 **6.3%**（主进程 ~2.8% + WebView ~3.5%），同条件
- [ ] 空闲成本与虫数成**反比**（可复现）：更轻的帧在 ProMotion 面板上维持更高的 rAF 频率（疑似 120Hz vs 60Hz），因此 1 虫空闲比 50 虫更贵。确认后可考虑限制渲染循环帧率（如 60fps），是低成本的后续优化；尚未做帧率插桩验证。
- [x] 隐藏虫子后 CPU 近 0 — **历史实测：** 隐藏约 **0.0%**，可见约 5.5%（debug，12 虫）。当前实现由共享可见状态事件暂停前端 rAF/音频，Rust 轮询直接根据原生可见状态跳过光标工作；隐藏路径在 0.4.x 未改动，复测需要托盘菜单自动化。
- [x] 设置窗口打开时覆盖层不冻结 — 设置默认隐藏，可从托盘打开；覆盖层独立
- [x] 睡眠唤醒后覆盖层恢复正常 — **通过（2026-09-16）。** 合盖 >30s 唤醒后主/副屏虫子与雨自动恢复。恢复路径：`system-resumed` → `force_rebuild_overlays`（关掉重建副屏，与手动切多显示器同路径）→ 刷新 viewport / 恢复音频。

### Debug（`pnpm tauri dev` · 上界参考）

含 Vite HMR 与 debug 代码，高于生产包：约 10–15%（1 虫）、4–5%（10 虫）、~3%（50 虫短采样）。

## 如何复跑 macOS soak

```bash
pnpm install
pnpm tauri dev          # 需要 Vite 在 :1420，不要单独跑 debug 二进制
```

生产形态请用 `pnpm tauri build` 后启动安装包；不要把裸 `cargo build --release` 当作发布产物。

### 原生隐藏 / 窗口截图验收（人工；待测）

1. 启动应用并选择「全部屏幕」，确认各屏均显示虫子。
2. 托盘选择「隐藏虫子」。macOS 按 `⌘⇧4` 后按空格，在各屏选择一个应用窗口；高亮与截图应属于该应用，没有 BugScurry 层。Windows 使用截图工具的窗口截图模式进行相同检查，桌面操作也应正常。
3. 保持隐藏，打开/关闭设置，并切换主屏/全部屏幕；再次截图，覆盖层不应重新出现或被选中。
4. 保持隐藏，睡眠至少 30 秒再唤醒，在各屏重复截图；隐藏期间插拔显示器也应保留该状态。
5. 托盘选择「显示虫子」；各目标屏的移动、音频（开启时）与点击捏死应恢复，且不抢键盘焦点。重复隐藏/显示，检查两个方向的切换。

### 截图偏好验收（人工；待测）

1. 显示虫子，保持默认 `showInCaptures` 关闭。未授予「输入监控」和「辅助功能」两种权限时，设置窗口应显示截图兼容提示。点击启用按钮，请求未获授权时应打开输入监控设置页。单独开启输入监控，确认截图检测可用、录制仍禁用；再单独开启辅助功能，确认无需同时开启输入监控即可检测截图并录制快捷键。macOS 按 `⌘⇧4` 后按空格：所有覆盖窗口应隐藏，能够选择下层应用，且保存该窗口截图应成功。各屏分别重复区域截图与 `⌘⇧5`。Windows 检查支持的截图工具能否排除覆盖层，桌面上的虫子应仍可见。
2. 完成或取消 macOS 截图（选择式截图：松开鼠标、Esc、Enter；工具栏截图：存成文件后自动恢复，存剪贴板时按 Esc，或用 `⌘⌃Esc` 停止录屏），会话结束后覆盖层应恢复且不抢焦点。截图前或期间通过托盘隐藏虫子再重复，退出时不应自动显示。截图期间切换显示器模式，重建覆盖层应保持临时隐藏。
3. 开启该偏好，macOS 截图界面期间覆盖窗口应保持可见，支持的捕获方式可包含覆盖层内容；无论偏好值如何，设置窗口都应可正常捕获。
4. 替换新构建后，确认授权对应当前安装的应用。若显示已授权但监听仍未就绪，界面应显示重试与重启提示，不能只留下没有解释的禁用录制按钮。
5. 隐藏虫子期间关闭偏好，再显示虫子；重启应用并切换显示器模式，确认持久化偏好应用于所有重建覆盖层。单独记录直接 `⌘⇧3` 截图、持续系统录屏与第三方工具的行为；这些场景在 macOS 不保证排除。录屏必须排除虫子时应从托盘隐藏。

### 睡眠唤醒 soak（人工）

1. `pnpm tauri dev` 或启动生产包，确认桌面有虫在爬。
2. 可选：托盘投喂一份食物、开雨，便于观察音频是否恢复。
3. 真正睡眠机器（苹果菜单 → 睡眠，或合盖）至少 30 秒。
4. 唤醒后检查：
   - **主屏与副屏**虫子都仍在各自屏幕范围内爬动（没有飞出、卡住，或副屏整层消失）
   - 若睡前开着雨，两块屏的雨丝都应恢复；雨声应在数秒内恢复
   - 点击虫子仍可捏死（穿透与命中正常）
   - 打开设置再关掉，应用不退出
5. 另测「全部清除」：应同时清掉虫子/食物/痕迹并停天气；再「重新生成」只出虫、不自动下天气。
