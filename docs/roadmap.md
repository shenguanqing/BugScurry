# 开发路线图

原则：先做出可玩的最小闭环，再扩能力；每个里程碑都可运行、可验收。

## M0 — 仓库与规范

- [x] Git 仓库初始化
- [x] 需求 / 架构 / 技术分析文档
- [x] README、LICENSE、.gitignore
- [x] 首次 commit 并 push 到 main

**产出**：文档齐全的仓库，技术选型冻结为 Tauri 2。

## M1 — MVP：一只虫可捏死

目标：验证「透明覆盖层 + 穿透 + 点击 + 简单动画」闭环。

- [x] 初始化 Tauri 2 + Vue 3 + TS + Vite + pnpm 工程
- [x] 透明、无边框、置顶、不出任务栏的覆盖层窗口
- [x] Canvas 绘制一只虫（几何体蟑螂）
- [x] 随机爬行、偶尔停顿、偶尔转向、朝向跟随
- [x] 虫子不移出可视区域
- [x] 透明区域鼠标穿透（Rust 轮询坐标 + 动态 ignore_cursor_events）
- [x] 点击虫子触发 squish
- [x] 1–2 秒淡出后重新生成
- [x] 基础托盘菜单（显示/隐藏、增减、重生、退出）

**验收**：见 `requirements.md` §6。macOS 已实机验证覆盖层显示；点击穿透/捏死需手动确认。

## M2 — 多虫 + 设置

1. BugManager 支持 1–50 只（逻辑已具备，接入设置 UI）；
2. 独立随机，不同步；
3. 设置窗口：数量、全部清除、重新生成；
4. 数量变更立即生效并持久化；
5. 完整托盘菜单文案与设置入口；
6. 大小、速度、随机度可调。

## M3 — 手感与效果

1. 更自然的昆虫运动（噪声、腿部动画、边缘滑行）；
2. 压扁形变打磨；
3. 音效开关与短音效；
4. 死亡痕迹 / 污渍开关（非血腥）；
5. 轻微粒子（可选）。

## M4 — 多显示器与系统集成

1. 当前屏幕 / 所有屏幕；
2. Retina / DPI 全路径校验；
3. 开机启动、始终运行；
4. 隐藏时停止计算；
5. CPU/内存 profile，50 虫压力测试。

## M5 — 打包与发布

1. macOS：DMG、签名与公证说明；
2. Windows：NSIS 安装包；
3. 开发/打包命令写入 README；
4. 版本号与变更记录。

## M6 — 虫种扩展（可选）

1. 虫种注册表落地；
2. 增加 Ant / Spider / Fly / Ladybug 中至少一种；
3. 设置中选择虫种。

## 风险与回退

| 风险 | 触发 | 缓解 |
|------|------|------|
| 穿透/点击切换抖动 | M1 实测 | 命中防抖；升级原生坐标转发 |
| 多屏坐标错乱 | M4 | 统一逻辑坐标层；分显示器窗口 |
| WebView 性能不足 | M1/M4 profile | 降特效；最后手段评估 Electron 回退 |
| macOS 权限弹窗 | 全局鼠标监听启用时 | 延后到可选增强，默认不用 |

## 完成定义（DoD）

每个里程碑合并前：

1. `pnpm typecheck` 通过；
2. `pnpm build` 通过；
3. 在至少一个目标平台上手动跑通验收点；
4. 涉及窗口行为时，记录 macOS / Windows 验证结果（缺平台时在 PR/说明中写明未验证项）。
