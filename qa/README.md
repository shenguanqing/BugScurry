# 本地测试台

运行 `pnpm dev`（或 `pnpm tauri dev`），访问：

- `http://localhost:1420/qa/index.html`
- 原书签 `http://localhost:1420/.tmp-species-qa/index.html` 由 Vite 开发服务器映射到同一页面。
- 直接打开天气：`http://localhost:1420/qa/index.html?panel=weather&kind=sand`

页面仅在开发服务器使用，不是生产构建入口，也不保存或广播应用设置。
代码在 `src/qa/`，纳入项目类型检查；不再维护被 Git 忽略的 `.tmp-species-qa/` 副本。

## 浏览器检查

- 虫种：保留 Emoji / Canvas、实际尺寸、居中、步态、捏扁和淡出对比。
- 天气与声音：全部 8 种天气、停止、随机选择、风向强度、深浅背景、声音开关。
- 暂停、逐帧和时间定位用于检查特定画面。暂停、停止、切回虫种或隐藏页面都会停止天气声音。
- 声音默认关闭，需手动开启。雾静音；雷阵雨包含闪电与延迟雷声。
- 页面自动执行虫种/天气渲染冒烟检查；这些检查不代替听感和真实桌面性能验证。
- 直接复用 `renderer.ts` 与 `rainAudio.ts`，天气菜单来自 `RAIN_KIND_ORDER`。

## 原生联调

Settings 底部说明连续点击 5 次，保留隐藏调试面板。它发送真实的桌面命令，
用于验证多屏、托盘、鼠标穿透、事件广播、喷雾冷却及应用声音开关。
浏览器测试台不连接 Tauri，不代替 macOS / Windows 原生联调。

## 事件与工具

菜单“事件与工具”包含全部五个随机事件（虫潮、胖虫入侵、狂暴冲刺、体型混乱、夜袭）和杀虫喷雾。
直接访问 `http://localhost:1420/.tmp-species-qa/index.html?panel=events`。
每次事件重建 12 只虫的独立场景；可选择播放标题，支持暂停、重置、喷雾音效。
使用应用同一份 BugManager、移动、渲染和事件分发；测试喷雾不设冷却，不写入每日统计。
切换菜单或隐藏页面暂停本地时间并停止喷雾声音。原生面板继续用于桌面集成验证。
